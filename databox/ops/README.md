# DBX-28 — Operational & release readiness

Operational material for the packaged Solid Databox deployment (`config/databox/live.json`).

- `runbooks.md` — operational procedures (key ceremony/rotation, tenant onboarding, backup/restore,
  incident response, relationship recovery, duty monitoring, retention), each grounded in the real
  component it operates.
- `hardening-checklist.md` — the security/privacy control checklist (verified vs open).
- `readiness-decision.md` — the signed readiness decision + residual-risk register.
- `sbom.cyclonedx.json` — CycloneDX SBOM, regenerated by `scripts/generate-sbom.js`.
- `dbx-27-conformance.json` (in `../conformance/`) — the DBX-27 evidence the readiness call leans on.
